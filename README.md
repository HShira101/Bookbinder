# Bookbinder — Journals as Books

[English](#english) · [Español](#español)

## English

Foundry VTT module that shows journals as a **book**: closed cover with the journal's name, two-page spreads, 3D page turns you can drag by hand, and a collapsible side index. System agnostic. Requires **Foundry VTT v14** or later.

> Version 0.1 is a prototype: one fixed look ("Book"). Customizable themes arrive in 0.2.

### Install
In Foundry: **Add-on Modules → Install Module → Manifest URL**:

```
https://github.com/HShira101/Bookbinder/releases/latest/download/module.json
```

### Use
1. Open a journal you own.
2. Click the **book icon** next to the window's close button (✕) and choose **Book**.
3. The journal now opens as a book for everyone. Choose **None (Foundry sheet)** to go back.

Turn pages with the side arrows, the page corners, the ← → keys (while the window has focus), or by dragging the page edge. Links to pages of the same journal turn the pages to them. The ✎ button on a page opens it in Foundry's editor.

Per-user settings: animation on/off, page-turn speed, index collapsed by default. Reduced motion is always respected.

## Español

Módulo de Foundry VTT que muestra los diarios como un **libro**: tapa cerrada con el nombre del diario, pliegos de dos páginas, paso de página en 3D que se puede arrastrar con la mano e índice lateral contraíble. Agnóstico de sistema. Requiere **Foundry VTT v14** o superior.

> La versión 0.1 es un prototipo: un único aspecto fijo ("Libro"). Los temas personalizables llegan en la 0.2.

### Instalar
En Foundry: **Módulos complementarios → Instalar módulo → URL del manifiesto**:

```
https://github.com/HShira101/Bookbinder/releases/latest/download/module.json
```

### Uso
1. Abre un diario del que seas propietario.
2. Pulsa el **icono de libro** junto al botón de cerrar (✕) de la ventana y elige **Libro**.
3. El diario se abre ahora como libro para todos. Elige **Ninguno (hoja de Foundry)** para volver.

Pasa las páginas con las flechas laterales, las esquinas de la página, las teclas ← → (con la ventana enfocada) o arrastrando el borde de la hoja. Los enlaces a páginas del mismo diario pasan las hojas hasta ellas. El botón ✎ de cada página la abre en el editor de Foundry.

Ajustes por usuario: animación sí/no, velocidad del paso de página, índice contraído por defecto. El movimiento reducido del sistema siempre se respeta.
